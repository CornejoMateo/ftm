### **Paso 2: Instalar Docker Desktop**

1. Descargar Docker Desktop desde: https://www.docker.com/products/docker-desktop
2. Instalar y reiniciar la PC
3. Abrir Docker Desktop y esperar que arranque
4. Reiniciar la PC
5. Chequear que en Docker Desktop no aparezca ningun error.
6. Marcar la casilla "Start Docker Desktop when you sign in to your computer"
7. Desmarcar la casilla "Open Docker Dashboard when Docker Desktop starts"
8. Cambiar en Settings → General → Desmarcar la opción “Use the WSL 2 based engine” → Aceptá y reiniciá Docker Desktop.
